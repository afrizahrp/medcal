# 10. Files That Should Be Used as Reference Templates (Phase 12)

Representasi terkuat untuk dipakai sebagai referensi desain (tanpa mengubah file aslinya):

- **`LK Otoscope.docx`** — contoh paling representatif dari struktur "umum"/baseline (identitas + lingkungan + fisik + keselamatan listrik + measurement sederhana + telaah teknis + tanda tangan), ukuran file sedang, 1 gambar saja.
- **`LK Autoclave.docx`** — contoh baik untuk device dengan measurement section bertingkat (3 sub-tabel) tapi masih terkelola.
- **`LK Bio Safety Cabinet.docx`** — contoh kasus paling kompleks (17 tabel, 6+ sub-measurement, teks kualitatif smoke-test) — baik untuk stress-test pendekatan templating di masa depan.
- **`LK Kelistrikan.docx`** — contoh paling sederhana (6 tabel, tanpa measurement section device-specific detail) — baseline minimum.
- **`LK Baby Incubator.docx`** — contoh dengan gambar besar/diagram tertanam dan sub-tabel banyak — baik untuk menguji penanganan gambar & tabel kompleks bersamaan.
